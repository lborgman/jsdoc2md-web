# A web version of jsdoc2md

> **This web tool is created with Claude AI:**
[Claude chat](https://claude.ai/share/dc67329f-c01d-40f6-99b6-a5a361bcb803)
So far I have made no changes myself. I have just tried to get Claude to fix some issues.

[jsdoc2md](https://github.com/jsdoc2md/jsdoc-to-markdown) is a command line tool that you can install on your desktop pc to extract JsDoc comments in markdown format.

This web version of *jsdoc2md* is a bit less powerful, but you do not have to install anything to use it. I think it is good enough to document exports in ES6 JavaScript module.
